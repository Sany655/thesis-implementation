# Dengue Prediction Research Resources

## Thesis Title
**Explainable AI-Based Early Severe Dengue Prediction using Lab + Clinical Data**

## Dataset Sources
- **Hospital Collaboration**: Direct data from clinical partners (Primary source).
- **Kaggle**: Public dengue datasets for benchmarking and pre-training.
- **WHO**: Dengue surveillance reports and severity markers.
- **Government Open Health Datasets**: Regional health data for epidemiology context.
- **Weather API Datasets**: Integration of temperature, humidity, and rainfall data.

## Methodology & Pipeline
1. **Data Collection**:
   - Lab Data (CBC, Platelets, HCT, etc.)
   - Clinical Symptoms (Fever, Vomiting, Pain, Bleeding)
   - Weather Data (Temporal/Regional)
   - Time-series Platelet data (Tracking drops)
2. **Modeling**:
   - Machine Learning (Random Forest, XGBoost)
   - Explainable AI (SHAP, LIME) for clinical trust.
3. **Delivery**:
   - Web Dashboard for clinical diagnostic support.
